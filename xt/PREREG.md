# Схема «как у канала» — предрегистрация 2026-11-22
Цель: проверить, даёт ли сопровождение сделки в стиле CryptoX прибыль с механическим входом.
Сопровождение (медианы из документа CryptoX 15.10): вход по рынку (открытие следующего 1h бара), SL −5.5%,
TP1 +1% (50%), после TP1 стоп в безубыток (вход + комиссии), TP2 +2.5% (25%), TP3 +6.7% (25%), лимит 72 ч.
Внутри бара консервативно: стоп раньше тейка; на баре TP1 остаток закрывается в BE, если бар задел вход.
Издержки: вход taker 0.05%, тейки maker 0.02%, стоп/BE/время taker 0.05% + 0.03% проскальзывание. Фандинг учтён.
Входы (1h, 24 ликвидных фьючерса, 2022-01…2026-10; holdout с 2026-06-01):
- R0 случайный (базовая линия, 2% баров, случайная сторона);
- R1 откат по тренду: BTC и монета над SMA200(1h), RSI14 < 30 → лонг; зеркально шорт;
- R2 вынос ликвидаций: за 4ч цена < −1.5 ATR и OI z < −1.5, BTC-режим up → лонг; зеркально шорт (цена вверх,
  OI вниз, режим down);
- R3 качественный пробой 36ч (оценка ≥5 из 6) по направлению BTC-режима;
- R4 импульс: монета в топ-3 по росту за 24ч и BTC-режим up → лонг; низ-3 и режим down → шорт.
Кулдаун 24ч на монету, ≤3 позиций одновременно.
Критерий: вход полезен, если на dev средний результат сделки > 0 после издержек с 95% ДИ бутстрапа выше 0,
и он лучше R0; holdout — подтверждение знака.

## Результат — ОТКЛОНЕНО
Случайный вход: 6531 сделка, WR 84%, средн. −0.28% номинала [−0.34; −0.22]. Откат по тренду −0.16%, вынос
ликвидаций −0.35%, импульс −0.33% (dev); на holdout тоже ниже нуля. Высокий WR (81–86%) — свойство схемы
(TP1 1% против SL 5.5%), а не входа. При риске ~13% на сделку (как у автора) счёт обнуляется при любом входе.
