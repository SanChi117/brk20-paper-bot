# Портфель «сильные против слабых» — предрегистрация 2026-11-22
Основа: ML-скрининг нашёл устойчивую предсказуемость относительной доходности монет (rel24 IC +0.04, t≈6),
съедаемую издержками при полной ежедневной смене позиций. Цель — снизить оборот, не трогая сигнал.
Основной вариант: модель на относительную доходность 72ч (те же 67 признаков, walk-forward по кварталам,
обучение только на прошлом), прогноз сглажен за 24ч; раз в сутки в 00:00 UTC: лонг в монеты, вошедшие в топ-4
по прогнозу, выход только при выпадении за топ-8; шорт зеркально. 50% капитала в лонгах, 50% в шортах, без плеча.
Издержки maker 0.03% на сторону; фандинг учитывается. Остальные варианты (taker, без гистерезиса, 3/10, ребаланс
раз в 3 дня, без сглаживания, rel24) — разведка.
Критерий: основной принимается, если 2023–май 2026 Шарп ≥ 1.0 и доходность > 0, в плюсе ≥ 60% кварталов,
и июнь–октябрь 2026 > 0; плюс должен сохраняться при taker-издержках (иначе зависит от исполнения лимитами).
