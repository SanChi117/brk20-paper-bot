# BRK-20 Paper Bot

Бумажный форвард-тест стратегии BRK-20 (4h пробой 20-дневного хая, пул 17 альтов).
Логика 1:1 из бэктеста bt_candidates19.py (191 сделка, PF 1.723, стресс 1.682).

**Бумажный режим: ордеров на бирже нет, API-ключи не нужны.**

## Установка (Ubuntu 24.04)

```
git clone https://github.com/SanChi117/brk20-paper-bot.git /root/brk20
cd /root/brk20 && bash install.sh
```

## Контроль

- `cat /root/brk20/status.txt` — одна строка: equity, сделки N/30, PF, гейт
- `tail -20 /root/brk20/journal.log` — события: сигналы, входы, стопы, трейл
- `cat /root/brk20/trades.csv` — все закрытые сделки
- `systemctl restart brk20` — перезапуск; `systemctl stop brk20` — стоп

## Форвард-гейт

30 закрытых сделок, PF > 1.2, риск 1% на сделку. Прошёл — разговор о реале.
Провалился — стратегия умирает здесь, дешево.

## Правила BRK-20

- Сигнал: закрытие 4h > максимум хаёв за 120 баров (20 дней, без текущего)
- Вход: buy-stop на уровне hi20, TTL 24h, прокол для исполнения 2 б.п.
- Стоп: entry − 1.75×ATR(14, 4h); сделка пропускается, если стоп > 20% цены
- +2R → стоп в безубыток (entry + комиссии)
- Трейл: подтверждённые пивот-лоу 4h (лаг 3) − 0.5×ATR, только вверх
- Риск 1% equity, максимум 2 позиции, одна на символ
- Данные: Binance Futures klines; fallback на Bybit при недоступности
