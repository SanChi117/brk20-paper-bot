# BRK-20 Paper Bot

Бумажный форвард-тест стратегии BRK-20 (4h пробой 20-дневного хая, пул 17 альтов).
Логика 1:1 из бэктеста bt_candidates19.py (191 сделка, PF 1.723, стресс 1.682).

**Бумажный режим: ордеров на бирже нет, API-ключи не нужны.**

## Установка (Ubuntu 24.04)

```
git clone https://github.com/SanChi117/brk20-paper-bot.git /root/brk20
cd /root/brk20 && bash install.sh
```

## Контроль

- `cat /root/brk20/status.txt` — одна строка: equity, сделки N/30, PF, гейт
- `tail -20 /root/brk20/journal.log` — события: сигналы, входы, стопы, трейл
- `cat /root/brk20/trades.csv` — все закрытые сделки
- `systemctl restart brk20` — перезапуск; `systemctl stop brk20` — стоп

## Слоты 5–6: бумажная копия канала CryptoX | ProTrading (с ноября 2026)

## Веб-терминал (v4)

Переключатель четырёх слотов в шапке, пул монет своей стратегии слева (с дистанцией до уровней входа), уровни стратегии

графиков лежит в репозитории (`web/lwc.js`) — терминал не зависит от внешнего CDN.

## Веб-терминал (v1.1)

```
cd /root/brk20 && bash install_web.sh
```

Установщик напечатает ссылку вида `http://IP:8080/?key=ТОКЕН` — **это единственный ключ к терминалу, сохрани её**. Терминал: свечной график (1h/4h) с линиями входа/стопа/BE, кривая equity, позиции, заявки, журнал. Кнопки: Пауза, Закрыть позицию, Отменить заявку.

- Управление идёт через `control.json` → бот применяет каждые 60 с
- `web_config.json` — порт и токен (генерируются при первом запуске)
- Логи терминала: `tail -20 /root/brk20/web.log`

## Правила BRK-20

- Сигнал: закрытие 4h > максимум хаёв за 120 баров (20 дней, без текущего)
- Вход: buy-stop на уровне hi20, TTL 24h, прокол для исполнения 2 б.п.
- Стоп: entry − 1.75×ATR(14, 4h); сделка пропускается, если стоп > 20% цены
- +2R → стоп в безубыток (entry + комиссии)
- Трейл: подтверждённые пивот-лоу 4h (лаг 3) − 0.5×ATR, только вверх
- Риск 1% equity, максимум 6 позиций (с 24.11.2026; было 2), одна на символ
- Данные: Binance Futures klines; fallback на Bybit при недоступности

## v1.3 — целостность бумажного исполнения (обязательно перезапустить гейт)

До v1.3 бот проверял часовые свечи *внутри* сигнальной 4h-свечи и записывал вход по уровню пробоя,
хотя сигнал появляется только на её закрытии, а цена к этому моменту уже выше уровня. Это завышало
результат каждой сделки. Исправлено:

- заявка действует только с первого часа после закрытия сигнальной 4h-свечи (`active_from`);
- вход = max(уровень, открытие бара) для лонга и min(...) для шорта; риск пересчитывается от фактического входа;
- стоп при гэпе исполняется по открытию бара; стоп в баре входа засчитывается сразу;
- ручные закрытия не входят в статистику гейта; `set_equity`/`set_risk` во время гейта отклоняются
  (разрешить: `BRK20_ALLOW_GATE_OVERRIDES=1`);
- веб: постоянное по времени сравнение ключа, ключ можно передавать заголовком `X-Key`,
  `BRK20_WEB_HOST=127.0.0.1` закрывает порт снаружи (доступ через SSH-туннель/HTTPS).

Тесты: `python3 -m unittest discover -s tests -v`.

**Результаты гейта, набранные до v1.3, недостоверны.** Бот архивирует их сам при первом запуске v1.3 (см. ниже).

## Автообновление (ставится один раз)

```
cd /root/brk20 && git fetch origin main && git checkout origin/main -- auto_update.sh install_autoupdate.sh brk20-update.service brk20-update.timer && bash install_autoupdate.sh
```

Дальше каждые 15 минут сервер сам забирает `main`, прогоняет тесты новой версии в отдельной папке и только
при успехе переключается и перезапускает `brk20`, `brk20s`, `brk20-web`. Если тесты не прошли — остаётся
старая версия. Правки, сделанные прямо на сервере, сохраняются в `archive/local_changes_*.patch`.
Журнал: `tail /root/brk20/update.log`. Отключить: `systemctl disable --now brk20-update.timer`.

При первом запуске новой логики исполнения (ENGINE 1.3) бот сам переносит старые `state`/`trades`/`journal`
в `archive/pre_engine_1.3_*` и начинает гейт заново.
