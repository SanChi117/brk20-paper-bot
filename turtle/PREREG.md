# Пробой дневного канала («черепахи») — предрегистрация 2026-11-22
Идея: сильные движения крипты длятся неделями. Покупаем, когда дневное закрытие выше максимума 20 предыдущих дней
(продаём при закрытии ниже минимума 20 дней), вход на открытии следующего дня. Стоп 2·ATR20. Выход — закрытие ниже
минимума 10 дней (для шорта — выше максимума 10), на открытии следующего дня. Без заглядывания вперёд: каналы
считаются по дням до сигнального включительно-исключительно (i−N … i−1), стоп в день входа учитывается.
Издержки: 0.05% комиссия + 0.05% проскальзывание на каждую сторону, фандинг из архива.
Основной вариант: A — 20/10 на BTC+ETH, лонг и шорт. Остальные (55/20, только лонг, топ-10, фильтр режима BTC/SMA200)
— разведка. Топ-10 составлен по сегодняшнему списку — есть ошибка выжившего, BTC+ETH её не имеют.
Критерий принятия A: dev PF ≥ 1.3 при ≥ 40 сделках, ΣR без топ-5 > 0, плюсовые больше половины лет.
Holdout (5 мес.) для трендовой системы мал — смотрится, но решающим не считается.

среди всех USDT-M с делистингом (без ошибки выжившего). Решение по боту — только после неё.
