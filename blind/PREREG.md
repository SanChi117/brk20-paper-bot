# Слепой тест «ИИ по скринам» — предрегистрация 2026-11-23
Цель: проверить, есть ли перевес у сетапов, которые ИИ даёт по скринам (1D/4H/1H/15m + данные), как это делает пользователь.
40 случайных моментов 2023–2026 на 24 монетах; монета и дата скрыты, цены × случайный коэффициент (0.1–10).
Ключ хранится только в закрытом кэше Actions. Сетапы фиксируются в blind/setups.json до оценки; правки после оценки запрещены.
Формат сетапа: сторона, лимитный вход, стоп, тейк, срок действия входа (часы); «нет сетапа» допустимо.
Оценка по 1h свечам: стоп раньше тейка внутри свечи; издержки 0.08% на сторону; удержание до 14 дней.
Перевес считается возможным, если процент попаданий выше безубыточного для планового RR и средний R > 0; при ~20–30 сделках
это только предварительный сигнал, для вывода нужна вторая независимая партия.
