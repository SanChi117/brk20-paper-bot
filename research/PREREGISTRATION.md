# Предрегистрация гипотез (записано ДО запуска, 2026-11-22)

Цель: проверить одну заранее заданную поправку к BRK-20 без подгонки параметров.

## H1 — BRK-20 лонг с фильтром режима BTC
- Правила BRK-20 без изменений (Donchian-120 на 4h, стоп 1.75 ATR, BE на +2R, трейл по пивотам), исполнение `fixed`.
- Новая сделка в лонг разрешена только если дневное закрытие BTCUSDT (последний закрытый день UTC) выше SMA200 дневных закрытий.
- Параметр SMA200 взят как общепринятый, не подбирался.

## H2 — BRK-20S шорт, зеркально
- Шорт разрешён только если закрытие BTC ниже SMA200.

## Критерии принятия (realistic costs: taker 0.05% + slip 0.05% на сторону + funding)
- PF ≥ 1.3 и нижняя граница 90% bootstrap CI PF > 1.0;
- прибыль без 5 лучших сделок > 0;
- не более одного убыточного календарного года;
- макс. просадка ≤ 25% при риске 1%.
Если не выполнено — гипотеза отвергается, повторный подбор параметров (SMA100/150 и т.п.) НЕ делается.

## Результат H1/H2 (2026-11-22): ОБЕ ОТВЕРГНУТЫ
- H1 лонг: PF 1.30, CI90 [0.93, 1.76], без топ-5 −149$, убыточные 2024 (≈0) и 2025, просадка 26.8%.
- H2 шорт: PF 1.07, CI90 [0.71, 1.53], без топ-5 −169$.
- Семейство BRK-20 → архив (лонг допускается только как контрольный paper-эталон).

# Кандидат B — OI flush reversal (записано ДО запуска, 2026-11-22)
Данные: Binance USD-M daily `metrics` (5-мин OI) → 1h; цены 1h; funding; 12 монет; 2022-01..2026-10.
- Сигнал на закрытии часа: z(доходность 4h) ≤ −2.5 И z(изменение OI за 4h) ≤ −2.5;
  z = значение / std за прошлые 720 часов. Порог 2.5 и окна не подбирались.
- B1 (основной): лонг, только при BTC выше SMA200 (дневной). B2: шорт-зеркало (цена ↑ z ≥ 2.5 и OI ↓ z ≤ −2.5) при BTC ниже SMA200.
- Вход: открытие следующего часа. Стоп: минимум 4 последних часов − 0.5·ATR14(1h) (лонг). Пропуск, если стоп > 10%.
- Выход: закрытие ≥ SMA24 → на открытии следующего часа; либо через 24 часа; стоп внутри бара с учётом гэпа.
- Риск 1%, максимум 2 позиции, комиссия 0.05% + проскальзывание 0.05% на сторону, funding.
- Критерии: ≥100 сделок, PF ≥ 1.3, нижняя граница CI90 > 1.0, без топ-5 > 0, не более 1 убыточного года, просадка ≤ 25%.
- Варианты «без режима» — только диагностика, решение по ним не принимается.
