# Новые листинги фьючерсов Binance и мемкоины — предрегистрация 2026-11-23

Вопрос: есть ли устойчивое преимущество в торговле монет сразу после листинга USDT-M фьючерса на Binance,
и улучшает ли результат автоматический «анализ проекта» (фильтры по признакам, известным на момент входа).

Данные: дневные свечи и фандинг всех USDT-M фьючерсов из архивов Binance, включая делистинг (кэш turtle).
Листинг = первая дневная свеча символа. Символы с данными от сентября 2020 (листинг раньше архива) исключены.
Dev: листинги до 2026-05-01. Holdout: листинги с 2026-05-01 (смотрится, не решает при малой выборке).

## Основной вариант (решающий)
Шорт новых листингов: вход на открытии дня 1 (день после дня листинга), держим 14 дней, стоп +40% от входа
(внутри дня по high; при гэпе — по открытию), выход на закрытии 14-го дня. Делистинг до выхода — по последнему закрытию.
Издержки 0.15% на сторону (комиссия + проскальзывание новых монет), фандинг из архива учитывается.
Критерий: ≥ 80 сделок в dev, PF ≥ 1.3, ΣR без топ-5 > 0, плюсовые ≥ 4 из 6 лет (2021–2026 dev).

## «Анализ проекта» — автоматические фильтры (разведка, только признаки на момент входа)
- новый токен vs старый: был ли спот на Binance раньше месяца листинга фьючерса (по архиву спота);
- мемкоин: категория meme на CoinGecko (текущий список — есть ошибка выжившего) + словарь известных мемов;
- первый день: рост/падение дня листинга (close/open дня 0), оборот дня 0;
- фандинг первых суток (толпа в лонг / в шорт).
Сетка (разведка): вход день 1/3/7, удержание 7/14/30, стоп 20/40/100%, а также зеркальный лонг.
Любой найденный фильтр считается гипотезой и требует отдельной проверки на holdout/следующих листингах.
